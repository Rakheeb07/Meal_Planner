# NutriGuide AI — Full 2,483-record meal planner dataset

## Contents
- `data/meal_planner_foods_all_records.csv`: all 2,483 records from the merged dataset, retaining names and meal categories, with standardized estimated serving/nutrition features.
- `data/source_merged_dataset_original.csv`: untouched source CSV for traceability.
- `data/dataset_report.json`: counts and estimation-method summary.
- `train.py`: fits a content-similarity KNN retrieval model over all records.
- `recommend.py`: filters meal candidates, ranks by calorie target, and diversifies results.
- `models/meal_knn_all_records.joblib`: trained fitted preprocessor + nearest-neighbour artifact (generated by `train.py`).

## Setup
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python train.py
python recommend.py --meal lunch --target-calories 400 --count 5
```

## Critical data note
All 2,483 rows are retained. To make every row available for development/demo recommendations, missing serving sizes and nutrition fields were estimated using a hierarchy: existing approximate canonical values; source-reported values treated as *assumed* per-100g where canonical values were absent; Atwater 4/4/9 energy from reported macros when possible; then category/meal median imputation. Serving size is kept if plausible, otherwise heuristically estimated from the food name/category. The 20 normalized prepared-meal candidates receive low-confidence heuristic values because their source features are normalized, not actual nutrient units. Every row is marked `estimated_values_are_verified=False`; allergen status is unknown; dietary safety filtering is disabled. Do not present these estimates as verified nutrition facts or use them for medical/allergy decisions.

## What the model is
This is a content-based similarity/retrieval model, not supervised preference prediction. There are no user like/dislike labels in the dataset. `Consume` means log consumption; `Regenerate` should exclude IDs already shown in the current session.

## Web-researched source guidance
Open Food Facts documents nutrient values with explicit per-100g and per-serving fields and serving size, and cautions that raw entered values can depend on the declared basis. Use its API only for matched packaged products and retain source/provenance. Docs: https://openfoodfacts.github.io/documentation/docs/Product-Opener/api/ and https://openfoodfacts.github.io/documentation/docs/Product-Opener/v2/search/get-search/ .
